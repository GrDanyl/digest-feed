# Тестовый выпуск

Это проверка доставки дайджеста в Telegram через GitHub Actions.

## Главное

- **Важный** пункт списка с жирным текстом.
- Обычный пункт со ссылкой: [репозиторий digest-feed](https://github.com/GrDanyl/digest-feed).
- Пункт с *курсивом* для проверки форматирования.

Если это сообщение пришло в Telegram — доставка работает.
